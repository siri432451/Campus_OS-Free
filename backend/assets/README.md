# Registrar signature and stamp

To print the Registrar's signature and the college stamp on **official** transcripts, add two PNG files here:

- `registrar-signature.png`  (transparent background, about 600 x 200 px)
- `registrar-stamp.png`      (transparent background, about 500 x 500 px)

If a file is missing, that item is simply left out of the PDF. Preview transcripts never show them.
